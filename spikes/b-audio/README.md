# Spike B: host-owned audio pipeline (disposable)

Results: `docs/research/audio-pipeline.md` (Spike B results) and ADR 0004.

- `lab/`: the `audiolab` CLI and library.
  - `bench`: decode CPU per stream from per-thread CPU counters
    (`GetThreadTimes`, `CLOCK_THREAD_CPUTIME_ID`). `--resample` adds rubato to
    48 kHz, `--fdk-all` routes all AAC to FDK for comparison.
  - `gapless`: decodes album tracks back to back and diffs against the source
    (`GAPLESS_CONTROL_INSERT=N` is the positive control).
  - `hls`: start and seek latency on local fixtures (served in-process with
    simulated RTT and bandwidth) or public URLs. `--streaming` decodes while a
    segment downloads.
  - `registry.rs`: the `Decoder` registry sketch. `ts.rs`: the MPEG-TS
    demuxer. `mp4edit.rs`: the MP4 edit-list and `iTunSMPB` reader.
- `player/`: the player core (decode thread → SPSC ring → cpal) behind UniFFI.
  `cargo run --release -p ristle-audio-spike --example play -- media/gapless 15`
  plays the album on the desktop.
- `android/`: Media3 `MediaSessionService` with a `SimpleBasePlayer` facade over
  the core, plus a minimal screen.

All media is synthetic and generated by `gen-media.sh` (ffmpeg with libmp3lame,
libvorbis and libopus; HE-AAC through `audiolab fdkenc`). Nothing is committed.

## Running

```sh
cargo build --release -p audiolab && ./gen-media.sh   # Windows numbers: target/release/audiolab bench ...
./build-android.sh                                     # audiolab CLI for x86_64 and arm64
./android-bench.sh <serial> results/<name>              # decode CPU + gapless on a device
./build-app.sh <serial> <x86_64|arm64-v8a>             # app + album
./soak.sh <serial> 30 results/soak-<name> [--doze]     # 30 min backgrounded, screen off
```

The scripts set `MSYS_NO_PATHCONV=1` because Git Bash otherwise rewrites
`/data/...` and `/sdcard/...` into Windows paths. `build-app.sh` needs the
Android Studio JBR and finds the VS-bundled cmake (for libopus) through
`vswhere`.

## Phone run (open item)

With the phone on adb (`adb devices` shows its serial):

1. `./android-bench.sh <serial> results/android-<model>`: about 5 minutes. It
   records the SoC, runs the decode benchmark unpinned and pinned to CPUs 0-3,
   and repeats the gapless check.
2. `./build-app.sh <serial> arm64-v8a`, then `./soak.sh <serial> 30 results/soak-<model>`.
   Unplug USB power if you use wireless adb. Otherwise add `--doze`, which fakes
   unplugged and idle. During the run the screen stays off. Pause and play are
   sent through the media session at minute 10 and "next" at minute 20.
3. Check the lock-screen controls by hand once: wake the phone and use
   pause, play and next on the lock-screen media card.
